## Text Elements
Protein Binder Design Campaign ^UEJGlLvB

Step One:
Generation ^GEdFhqeI

1) Epitope selection:
We can select multiple or the hotspot range
2) Target definition: already defined with DIO3 cut verison  ^QBDQVGRf

Step Two:
Generation First Pass ^ktztzCeC

Models Pool:
1) Hallucination based (mosaic):
We can use different folding models(boltz2, af2, of3, proteinx)
hallucination->folder->proteinmpnn->loss
2) Boltzgen: cheap design/lower quality per design ->increase quantity. 
Worth looking, mosaic fine tuned version. 
3) Proteina-complexa: speed comparable to boltzgen + beam search 
4) RFDiffusion ^1mbZu18Z

Parameters: 
1) binder length: 60-100? 
2)Loss configs: we can write 4-5 losses to use 
each of them.
3) helices minimization (gen models tend to generate more)
4) control aa frequencies  ^NTbl2OvN

Step Three
filtering
 ^5u8VdvoX

1) check aa frequencies for unrealistic distributions
2) self consistency filter:
sequences->different folder->mpnn-> n sequences ->fold them->check sim structure

3) Ensamble scoring: 
For each binder-> n folders-> get affinity/loss value (importantly, exclude optimized folder)

4) Hold-out one folding model for final evaluation ^we3klD3F

Step Four
Clustering
 ^QUZF9tRV

Since we want to enforce diversity: 

We cluster each candidate using:
1) sequence identity (esm-c?)
2) Foldseek structure clusters
3) Pose Clustering:
candidates-> folder (unique)-> create anchor (so we can compare each 
binder on the same frame);
Then, we can compute the Interface fingerprints:For each design, take the set of target 
residues within ~5 Å of any binder atom. 
Jaccard distance between those sets → epitope clusters 

and a axis/frame similarity between structures

Finally, we obtain K clusters with n binders each-> we sample from them for optimization  ^0CoVGhEL

Step Five:
Optimization and Ranking 
 ^bpGFiHHw

We sample, uniform budget, each cluster (we could add noise here): take the best from a cluster 
start optimization, fix interface hotspots, apply different temperature on mpnn. 

From a cluster we can generate N new optimized candidates

Rank the best candidates using an held-out folding model (add some negatives as well) ^n4ttJTHS
