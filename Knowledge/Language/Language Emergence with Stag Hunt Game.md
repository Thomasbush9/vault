## Setup:

Env:

A 2D world map of positions in xy coordinates. In the map there are structural objects like walls (?) with some features that we can give them. Reward objects of two kinds (small rewards, big rewards). Rules: big rewards can only be achieved by cooperation (maybe the two agents must be close to the object for t times or something like that) of the agents otherwise penalty? while small rewards can be achieved by agents alone.

Agents:  They have a perception module to perceive rewards, other agent?, env. A Communication channel to express messages, reward system to optimise.

Additional things that we can control: population of agents, communication on/off, rewards and risk, env space etc.
