# Data

Pointers to where data and run artifacts live. This file is a lookup, not a story.

- Dataset (scenes): `/n/holylfs06/LABS/bsabatini_lab/Everyone/tbush/language/data/scenes_grid_iid_10k/{train,val,test}` — sharded `.pt` files with `target_crop` (64x64 uint8), `scene` (128x128 uint8), `target_cell` (0–15), `objects` (per-example list of dicts: shape, color, cell, is_target).

## Datasets

- `scenes_grid_iid_10k` — synthetic 4x4 grid scenes, 6 shapes x 6 colors (36 combos), IID splits, ~10k examples. Generated by the sibling `language` project (config in the dataset dir).

## Run IDs

- `runs/basin_experiments/` — 2026-07-11, fixed vision (seed_1 checkpoints), 3 arms x 20 game seeds x 40 epochs. `runs/*.json` per-run histories (cache), `models/*.pt` for successful runs only, `summary.json`.
- Figures: `figures/seed_sweep.*`, `figures/basin_experiments_*.png/pdf`, plus per-stage sanity figures from `egg_start.py`.
